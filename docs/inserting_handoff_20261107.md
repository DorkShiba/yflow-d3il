3. 진행 중인 I12는 아직 `results.json`·`rollouts.json`이 없고 상세 결과가 프로세스 메모리에 있다. Console snapshot은 진행 사실을 남길 뿐 중간 상태 복구용 checkpoint가 아니다. 현재 runner는 rollout 중간부터 재개하지 않으며, 완료 전에 중단되면 I12는 같은 평가 목록 전체를 다시 실행해야 한다. 가능하면 해당 조합이 완료되어 `COMPLETE.json`이 생긴 뒤 복사하고, 실행 중 복사본은 완료 시 다시 동기화한다.
